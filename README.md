# The Elysean

Static landing page. No build step — open `index.html` or serve the folder:

```bash
python3 -m http.server 8000
```

## Edit
- **Contract address / burn numbers:** `CONFIG` at the top of `script.js`.
- **Background video:** put `assets/hero.mp4` (and/or `hero.webm`) in `assets/`. If it's full-bleed, set `--media-width: 100%` in `styles.css`.
- **Links:** X → https://x.com/theelysean, Volta → https://www.volta.family/ (in `index.html`).
